## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
There needs to be a way to save a given configuration of modules, along with their conntections, so a layout/flow/whatever can be pulled up again. This will roughly map to the idea of a saved session in a conventional DAW. A challenge here will be handling multiplexing. We don't know what will be used for multiplexing and don't want to nail it down, but the saved session should restore the modules in the same layout.
